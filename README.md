## 💻 System Architecture & Engineering Philosophy

As a Computer Engineer, I don't just write code; I architect systems. My focus lies at the intersection of **Cross-Platform Software Engineering**, **Local Database Integrity**, and **Artificial Intelligence**. I specialize in building solutions that require heavy local processing, precise state management, and real-time data analysis.

- ⚙️ **Offline-First Architectures:** Specializing in bypassing standard web limits to build deeply integrated desktop ecosystems using **React, Electron, and SQLite**.
- 🧠 **AI & Computer Vision:** Moving beyond simple API calls to train custom **YOLOv8** models, calculate dynamic metrics, and build real-time visual processing pipelines.
- 🔐 **Native Security:** Architecting mobile solutions with **Flutter/Dart** that prioritize device-level integrity and secure data handling.
- 🔬 **Algorithmic R&D:** Utilizing meta-heuristic optimization techniques (Genetic, PSO, ABC) to solve complex routing and resource allocation problems.
